## Research directions

My recent work connects control, optimization, and robotics: using minimum-energy controlled gradient flow to study nonconvex loss landscapes, extending nonlinear Gramian methods toward state-to-state steering for RRT*/PRM-style planning, and studying experiment design when robot interactions can irreversibly remove future measurements.
